Follow-ups none required for this ADR

Review correction

Each HTTP test fixture now supplies a fresh Map, avoiding rare random collisions across tests, and the old-caller test checks six-hex format. The production callback still uses the same single process-local Map; final-code HTTP and restart probes above confirmed it.

Accepted operating risks

Unauthenticated callers can squat on names. A restart drops every redirect, and separate processes have separate maps. The six-hex generated space is finite; this build adds collision avoidance, not persistence or capacity management. These are the explicit D4 / D5 trade-offs, not unverified implementation tasks.

No ADR amendment

No chosen decision changed. No test or matrix case is deferred, failed or untested; no follow-up implementation was introduced.
